# Spec: 体感模式

> 自根级 `TODO.md`「P1 — 真机扫尾」迁入（2026-08-26）。优先级：P1。平台：仅 Android（依赖手机传感器）。

## 需求（数值以 `docs/re/02` §4.4 为准，动手前先核对）

- 通道：IB 包 257 / 260
- 缩放系数：
  - 加速度计：x ×2000 / y ×−2000 / z ×1000
  - 陀螺仪：×286.47888
- 节流：每类事件 ≥50 ms
- 需读取 Android 加速度计 + 陀螺仪传感器

## 实现约束

- 高频传感器数据必须过 50 ms/类节流后再入队；发送沿用 `ib-send` 单线程 FIFO，不得在调用线程直写 socket（NetworkOnMainThreadException 红线，见根 AGENTS.md Common Patterns）

## 验收标准

- Android 真机开启体感模式后 TV 端随姿态响应
- 长时间晃动不丢连接、不明显延迟（节流生效）
